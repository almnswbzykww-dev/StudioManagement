# نظام إدارة استديو التصوير والطباعة المتكامل
## StudioManagement - Photography & Digital Printing Enterprise System

نظام تجاري واحترافي متكامل مصمم خصيصاً لإدارة استديوهات التصوير الفوتوغرافي ومعامل الطباعة الرقمية والحرارية والدعائية.

---

### 🌟 المميزات والأقسام الرئيسية

1. **👰 لوحات العرسان الفاخرة (Wedding Boards)**:
   - إدارة مقاسات اللوحات الملكية (60×90، 80×120، 100×150 سم).
   - خيارات الإطارات الخشبية، الأكريليك، وتخصيص إضاءة الـ LED المخفية.

2. **📷 الصور وجلسات الاستديو (Studio Photos)**:
   - جلسات تصوير شخصية، عائلية، أطفال، حفلات تخرج، وصور الجوازات الرسمية 4×6.

3. **📢 الدعاية والإعلان والبنرات (Advertising & Signage)**:
   - طباعة بنرات فليكس، فينيل، ستيكرات، رول اب، وحروف بارزة وحساب المساحات والتكلفة.

4. **🎨 التصميمات والجرافيك (Graphic Designs)**:
   - تصميم الهويات التجارية، كروت شخصية فاخرة، بروشورات، وبطاقات دعوات رقمية.

5. **📚 ألبومات الصور الفاخرة (Photo Albums)**:
   - ألبومات زفاف ديجيتال حرارية، جلد إيطالي، زجاج أكريليك، وصناديق خشب محفورة بالليزر.

6. **🎬 الفيديو والمونتاج (Video Production & Montage)**:
   - تصوير سينمائي 4K، تصوير درون جوي، مونتاج إعلاني ومناسبات وتيزرات.

7. **📸 التصوير الخارجي والمناسبات (Outdoor Photography)**:
   - تغطية مناسبات وأفراح في حدائق ومنتجعات مع إضاءة متنقلة وفريق عمل خارجي.

8. **🔥 الطباعة الحرارية والهدايا (Thermal Sublimation)**:
   - طباعة سبلميشن للتيشيرتات، الأكواب السحرية، دروع الكريستال والخشب والهدايا التذكارية.

9. **👥 إدارة العملاء (Customers)**:
   - كشف حساب العميل، سجل الطلبات، المديونية السابقة، والتواصل المباشر عبر واتساب.

10. **💳 نظام الدفع والتحصيل الموحد (Unified Payment System)**:
    - **دفع نقدي (Cash)**: سندات قبض، كاشير، تاريخ ووقت وملاحظات.
    - **دفع بنكي ومحافظ إلكترونية (E-Wallets)**:
      - 💳 جيب (Jeeb)
      - 💳 جوالي (Jawwali)
      - 💳 ون كاش (OneCash)
      - 💳 فلوسك (Floosak)
      - 💳 كريمي / إم فلوس (Kuraimi)
      مع تسجيل رقم العملية (TX ID)، رقم الحوالة، اسم وهاتف المحول، وإرفاق الإشعار.
    - **دفعات متعددة (Multiple Payments)**: تسديد الطلب على أقساط ودفعات مع سجل تفصيلي آلي.

11. **🧾 الفواتير والطباعة (Invoices & Printing)**:
    - قالب فاتورة رسمي A4 وقالب إيصال حراري POS 80mm.
    - شعار الاستديو، الباركود، الشروط، تفاصيل الدفعات، والطباعة المباشرة عبر المتصفح.

12. **💰 المحاسبة والصندوق (Accounting & Treasury)**:
    - حركة الخزينة والمحافظ الإلكترونية، الإيرادات، المصروفات، وتدقيق وردية الكاشير.

13. **📦 المخزون والموردون (Inventory & Suppliers)**:
    - إدارة ورق التصوير، الأحبار، ألواح الخشب، مع تنبيه تلقائي بالأصناف التي قاربت على النفاد، وفواتير المشتريات.

14. **👔 الموظفون والرواتب (Employees & Payroll)**:
    - إدارة الكادر، تسجيل السلف وخصمها آلياً عند صرف الرواتب الشهرية.

15. **📊 مركز التقارير الشامل (12 تقرير)**:
    - تقارير المبيعات، الأرباح، حركة الصندوق، الديون، والمخزون، مع تصدير Excel/CSV والطباعة.

16. **🛡️ سجل العمليات والأمان (Audit Log)**:
    - تسجيل تدقيق غير قابل للتعديل لكافة العمليات والمدفوعات والمستخدمين.

17. **💾 النسخ الاحتياطي والاستعادة (Backup & Restore)**:
    - تصدير كامل لقاعدة بيانات الاستديو بملف JSON مستقل مع آلية استعادة موثوقة.

### 🚀 متطلبات وتشغيل المشروع

#### 1. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

#### 2. تشغيل بيئة التطوير (Run Development Server)
```bash
npm run dev
```
يعمل التطبيق افتراضياً على المنفذ: `http://localhost:3000`

#### 3. بناء النسخة الإنتاجية (Production Build)
```bash
npm run build
```

---

### 🛠️ التقنيات المستخدمة

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 (Full RTL Arabic Typography)
- **Icons**: Lucide React
- **Local Database**: IndexedDB / LocalStorage Engine with JSON Export/Import
- **Printing**: Native CSS `@media print` with Multi-format support (A4 / 80mm Thermal POS)
